# umlmeta

Clean-room Python implementation of the **UML 2.5.1 metamodel** and the **SysML v1 → v2
transformation**, generated from OMG-published XMI and validated against the
[sysmlpy](https://github.com/mycr0ft/sysmlpy) v2 reader.

No vendor tooling, no UML/SysML libraries — the generated packages are pure
stdlib, and every semantic in them is traceable to an OMG document.

| `umlmeta.v1_to_v2_as` | SysML v1 → v2 **abstract-syntax transformer** (conformance **R3**, ptc/2025-04-07 §2): transforms `umlmeta.uml25`+`umlmeta.sysml` objects (R1 artifacts) into `umlmeta.sysml2` objects (R2 artifacts) — Block→PartDefinition, Property→PartUsage/AttributeUsage/OccurrenceUsage via FeatureMembership + FeatureTyping, Generalization→Subclassification, Comment→Documentation; one AS object per v1 element, same honesty rule as the textual emitter | `check_v1_to_v2_as.py` 238 |
| `umlmeta.v2_text` | **AS → SysML v2 textual notation** (pathway M2a, "single form notation"): renders the transformed `umlmeta.sysml2` graph in the same vocabulary the calibrated `v1_to_v2` emitter writes — definitions, usages, typing/multiplicity/subsetting/redefinition suffixes, documentation, activity nodes/edges/transitions, state machines, requirements/satisfy, interactions, imports — so the AS (not the v1 model) is the source of truth for what is written; byte-identical to the textual pipeline on the parity model and sysmlpy-validated. Unknown AS metaclasses raise `UnsupportedEmission` instead of being dropped | `check_v1_to_v2_as.py` M2 section |
| `umlmeta.sync` | **pair diff + three-way sync** (pathway M3): every element is classified by who changed it since the link snapshot — v1-only (the fresh mapping wins), v2-only (the hand edit is preserved), both (`both-changed` conflict; v2 wins), v1-deleted (`deleted-in-v1-edited-in-v2` when also edited), v2-native (kept), plus `blocked-by-edited-container` when a re-mapped child's container was edited v2-side. Rename/move repair (M3b): records carry a name-independent `v1_key`, a unique match re-points the fresh mapping onto the known identity, descendants follow by path suffix, identical siblings are refused as `ambiguous-rename`. Change detection is one content signature (scalars + references as `kind:name`) shared with the provenance record; a re-mapped child rebuilds its content ancestors, so edits are never smuggled into a stale subtree | `check_v1_to_v2_as.py` M3 section |
| `umlmeta.v2_json` | **AS → JSON persistence** (pathway M2b): a metaclass-shaped document (`format: umlmeta.v2json/1`) — `@type` is the AS metaclass, `@id` is the link elementId, containment rides `ownedRelationship` — that reads back into an AS graph with identities, member order and scalar features intact (write→read→write is a byte-identical fixed point; malformed documents rejected). Interop, measured: sysmlpy's interchange is a visitor parse-tree mirror, so the crossing is the text notation (M2a) or a `@type` adapter; opensysml consumes metaclass/KerML-shaped models | `check_v1_to_v2_as.py` M2b section |
| `umlmeta.link` | **v1 ↔ v2 linkage layer** (pathway: `docs/v1-v2-linkage-pathway.md`, milestone M1): deterministic SysML v2 `elementId` (uuid5 over the declared path + metaclass — sysmlpy's stable-identity recipe in the umlmeta link namespace — occurrence tie-breaker for same-name siblings, parent-anchored for anonymous elements), `provenance()` records joining each v2 element to its v1 source (kind, path, `xmi:id` as a per-snapshot cache, v1 content signature) through the transform's retained index, and `graph_hash()` — a semantic content hash over the AS graph; `adopt=True` is the reconcile/L3 hook | `check_v1_to_v2_as.py` M1 section |

**701 checks, all green.** `REPORT.md` is the detailed build journal: dialect facts,
mapping tables with spec anchors, calibration evidence, and honest elisions.
`docs/v1-v2-linkage-pathway.md` is the plan for the layer above the mapping:
maintaining a v1 ↔ v2 link (stable identity, provenance, persistence, sync,
elision ledger) through a prolonged transition period.

## Quick start

The check suites for the metamodel and profiles are stdlib-only; the emitter
suites validate with [sysmlpy](https://github.com/mycr0ft/sysmlpy) (the
authoritative SysML v2 reader), and the generator/reader need `lxml`:

```bash
python check.py                 # UML metamodel: 45 checks (stdlib only)
python check_profiles.py        # profiles (Std + SysML + UAF 1.2 + UAF 1.3): 60 checks (stdlib only)
python check_bpmn.py            # BPMN 2.0.2 CMOF metamodel: 25 checks (stdlib only)
python check_sysml2.py          # SysML v2 abstract syntax: 26 checks (stdlib only)
python check_emof_write.py      # EMOF writer: 18 checks (stdlib only)
python check_ocl.py             # OCL translation: 19 checks (stdlib only)

# these need the sysmlpy reader and/or the OMG corpora
$SYSMLPY_PYTHON check_v1_to_v2.py    # v1->v2 emitter: 47 checks
$SYSMLPY_PYTHON check_dodaf.py       # XMI end-to-end: 32 checks
                                #   (needs lxml + DoDAFLibrary.xmi, see REPORT Part 4)

# the generators need lxml and write into src/umlmeta/
$LXML_PYTHON generate.py           # regenerate src/umlmeta/uml25.py
$LXML_PYTHON generate_profiles.py  # regenerate the profiles
```

The check scripts print every assertion; a failing assertion names the mapping.
`check_v1_to_v2.py` also writes `vehicle_example_v2.sysml`, `wave3_example_v2.sysml`,
and `wave4_example_v2.sysml` — worked examples of the emitted notation.

## Install

```bash
pip install umlmeta              # the generated metamodel and the library
pip install "umlmeta[xmi]"       # + lxml, for the XMI/CMOF/EMOF readers and writers
```

The generated metamodel modules are pure stdlib; `lxml` is only needed by the
readers, writers and generators.

```python
from umlmeta import uml25
from umlmeta import derived, query
```

## Clean-room discipline

- The generator and emitter are written from **normative OMG text only**
  (UML 2.5.1 XMI, profile XMI, the ptc/2025-04-07 transformation spec).
  Reference extractions and example XMI corpora are **kept out of the
  repository** (e.g. the local `transition.txt` spec dump is git-ignored).
- The only instance-model corpus used for reader tests is the
  OMG-published `DoDAFLibrary.xmi` (UPDM example). Third-party commercial
  book models are **excluded on copyright grounds**.
- The emitter follows an **honesty rule**: elements with no normative
  mapping raise `UnmappedFeature` naming the v1 metaclass rather than
  guessing, and spec gaps (e.g. ProxyPort, SYSML2_-329) surface as
  explicit comments.
