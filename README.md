# uml2py

Clean-room Python implementation of the **UML 2.5.1 metamodel** and the **SysML v1 → v2
transformation**, generated from OMG-published XMI and validated against the
[sysmlpy](https://github.com/mycr0ft/sysmlpy) v2 reader.

No vendor tooling, no UML/SysML libraries — the generated packages are pure
stdlib, and every semantic in them is traceable to an OMG document.

mapping tables with spec anchors, calibration evidence, and honest elisions.

## Quick start

The check suites for the metamodel and profiles are stdlib-only; the emitter
suites validate with [sysmlpy](https://github.com/mycr0ft/sysmlpy) (the
authoritative SysML v2 reader), and the generator/reader need `lxml`:

```bash
python check.py                 # UML metamodel: 45 checks (stdlib only)
python check_profiles.py        # profiles (Std + SysML + UAF 1.2 + UAF 1.3): 60 checks (stdlib only)
python check_bpmn.py            # BPMN 2.0.2 CMOF metamodel: 25 checks (stdlib only)
~/Projects/sysmlpy/.venv/bin/python check_v1_to_v2.py    # v1->v2 emitter: 47 checks
~/Projects/sysmlpy/.venv/bin/python check_dodaf.py       # XMI end-to-end: 32 checks
                                #   (needs lxml + DoDAFLibrary.xmi, see REPORT Part 4)
~/Projects/ams-gra-sim/.venv/bin/python generate.py           # regenerate gen/uml25.py (lxml)
~/Projects/ams-gra-sim/.venv/bin/python generate_profiles.py  # regenerate the profiles (lxml)
```

The check scripts print every assertion; a failing assertion names the mapping.
`check_v1_to_v2.py` also writes `vehicle_example_v2.sysml`, `wave3_example_v2.sysml`,
and `wave4_example_v2.sysml` — worked examples of the emitted notation.

## Clean-room discipline

- The generator and emitter are written from **normative OMG text only**
  (UML 2.5.1 XMI, profile XMI, the ptc/2025-04-07 transformation spec).
  Reference extractions and example XMI corpora are **kept out of the
  repository** (e.g. the local `transition.txt` spec dump is git-ignored).
- The only instance-model corpus used for reader tests is the
  OMG-published `DoDAFLibrary.xmi` (UPDM example). Third-party commercial
  book models are **excluded on copyright grounds**.
- The emitter follows an **honesty rule**: elements with no normative
  mapping raise `UnmappedFeature` naming the v1 metaclass rather than
  guessing, and spec gaps (e.g. ProxyPort, SYSML2_-329) surface as
  explicit comments.
